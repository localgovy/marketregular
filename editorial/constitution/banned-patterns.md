# MarketRegular Banned and Suspect Patterns

Version: 0.1

## Hard bans

Fabricated visits.

Fabricated conversations.

Fabricated tastes or smells.

Invented current product availability.

Invented current vendor attendance.

Unsupported superlatives.

Database classifications presented as normal prose.

Instructions to imitate a named living writer.

## Behavioural anti-pattern

If a phrase exists mainly to make an ordinary fact sound literary:

1. replace it with the ordinary fact
2. determine what the actual editorial insight is
3. express that insight precisely

## Important

This file is not a thesaurus of forbidden words.

Context matters.

The real target is synthetic writing behaviour.
